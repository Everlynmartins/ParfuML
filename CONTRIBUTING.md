# Contribuindo

Contribuições de código, testes e documentação são bem-vindas.

1. Não inclua planilhas brutas, URLs de compra, nomes de lojas, ofertas individuais, dados pessoais, credenciais ou modelos serializados.
2. Execute `npm ci` e `npm test` antes de abrir um pull request.
3. Para alterações no site estático, execute também o build e `npm run test:pages` com o base path `/ParfuML`.
4. Explique a motivação, o impacto e as verificações realizadas.
5. Vulnerabilidades devem ser relatadas pela aba Security, não em issues públicas.

Ao contribuir, você declara ter direito de disponibilizar o conteúdo enviado sob as licenças aplicáveis do repositório.
