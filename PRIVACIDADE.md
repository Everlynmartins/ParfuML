# Aviso de Privacidade

Atualizado em 16 de agosto de 2026.

## Responsável e contato

O responsável pelo projeto define as finalidades do site, que é educacional e
não comercial. Para dúvidas de privacidade ou solicitações relacionadas aos
direitos da LGPD, use o [perfil público do projeto](https://github.com/Everlynmartins).
Não envie dados pessoais em issues ou discussões públicas.

O ParfuML é um recomendador estático de perfumes. As escolhas do questionário são processadas localmente no navegador para calcular sugestões e não são enviadas, armazenadas ou associadas a uma pessoa.

O código do projeto não solicita cadastro e não coleta nome, e-mail, telefone, CPF, endereço, senha, dados de pagamento ou respostas do questionário. Também não instala cookies próprios, analytics, pixels de publicidade nem banco de dados de usuários.

O site é hospedado no GitHub Pages. Segundo a [documentação do serviço](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages), o GitHub registra e armazena o endereço IP do visitante para finalidades de segurança, mesmo quando a pessoa não está conectada. O provedor também pode tratar outros dados técnicos conforme sua [declaração de privacidade](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). O ParfuML não recebe esses registros por meio da aplicação nem os usa para identificar visitantes.

O projeto não define o prazo de retenção dos registros técnicos mantidos pelo
GitHub e não consegue eliminá-los diretamente. Esses aspectos dependem dos
controles e da política do provedor de hospedagem.

O catálogo público reúne dados agregados de produtos, preços observados e notas olfativas, não dados de consumidores. Não são publicados nomes de lojas, vendedores, SKUs, estoque individual ou URLs de compra. Caso o projeto passe a coletar dados, usar cookies não essenciais, analytics, login ou personalização persistente, este aviso será atualizado antes da ativação.
